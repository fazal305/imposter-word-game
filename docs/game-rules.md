# Game Rules

## Setup

- 3–12 players, each given a unique name.
- Choose a word category (or "All Categories") and difficulty (or "Any").
- Optionally enable **No-word Imposter**, where the Imposter gets no word at
  all instead of a related decoy word.

## Roles

- Every player except one ("Agents") receives the same secret word.
- One randomly chosen player (the "Imposter") receives a different word from
  the same related pair — related enough that a good bluff is possible, but
  different enough that careless clues can expose it.

## Round flow

1. **Reveal** — the phone is passed to each player in turn. Each player
   presses and holds a card to see their own role and word, then explicitly
   confirms before passing the phone on.
2. **Discussion** — players take turns giving a single clue about their
   word, out loud, without saying the word itself. This game does not
   capture or display spoken clues; it only shows whose turn it is.
3. **Voting** — the phone is passed to each player again for a private
   ballot. Each voter picks one other player they suspect is the Imposter
   and confirms. No vote is shown to anyone until every player has voted.
4. **Results** — the full vote tally is revealed, along with whether the
   Imposter was caught.
5. **Game over** — every player's role and both secret words are revealed.

## Winning

- **Agents win** if the player with the most votes is the Imposter.
- **Imposter wins** if the player with the most votes is not the Imposter,
  or if voting ends in a tie for the most votes (a tie means the group
  couldn't agree, so no one is eliminated and the Imposter escapes).

This is a single-round game: there is no multi-round elimination chain in
this version (see the roadmap in the main README).

## Rematch

- **Play Again** keeps the same players and settings, and immediately starts
  a new round with a freshly chosen word pair and Imposter.
- **New Game** returns to a blank setup screen.
